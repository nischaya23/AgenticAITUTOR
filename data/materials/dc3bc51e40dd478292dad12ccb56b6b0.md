# Binary Search
Binary search halves a sorted search interval. For a lower-bound search use a half-open interval [left,right). If a[mid] < target set left=mid+1, otherwise right=mid. The invariant is: all indices before left have values below target; all indices at or beyond right have values at least target. At left=right the insertion index is left. Time complexity is O(log n).
# Loop Invariants
An invariant holds initially, is preserved by each iteration, and yields the result on termination. Sorted arrays are a prerequisite for binary search.
